# ProxyK Admin 0.2.0

Первый релиз этапа 2. Через `vpn-user` по SSH можно создавать, переименовывать,
включать, отключать и удалять VPN-пользователей, выдавать ссылки VLESS/REALITY
и читать текущие счётчики трафика Xray. Пользователи хранятся в SQLite и
восстанавливаются в Xray после перезапуска.

Для обновления стандартной установки v0.1.2 выполните команду по SSH.

```bash
curl -fsSL https://github.com/kkirill412/proxyk-admin-linux/releases/download/v0.2.0/install.sh | sudo bash -s -- --upgrade
```

Скрипт сохраняет резервную копию базы, прежний код и Compose. Порты, сертификаты
и ключи REALITY сохраняются. Для новой установки запустите команду без `--upgrade`.

Отключение пользователя закрывает новые подключения после синхронизации.
Счётчики трафика сбрасываются при перезапуске Xray. Вход через веб-панель
относится к этапу 3. Релиз опубликован с пометкой `prerelease`.
