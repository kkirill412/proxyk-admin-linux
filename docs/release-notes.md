# ProxyK Admin 0.1.2

Исправление установки через `curl | sudo bash` на Python без поддержки фильтров
распаковки архивов, включая ранние Python 3.10/3.11.

- Устранена ошибка `TarFile.extractall() got an unexpected keyword argument 'filter'`.
- Архив распаковывается без `extractall`: копируются только проверенные обычные
  файлы и каталоги. Выход за каталог, ссылки и специальные файлы запрещены;
  владельцы и специальные права из архива не применяются.
- Добавлены проверки совместимости и отклонения небезопасных архивов.
- Автоматическая установка Docker Engine и Compose Plugin сохранена.

Установка:

```bash
curl -fsSL https://github.com/kkirill412/proxyk-admin-linux/releases/download/v0.1.2/install.sh | sudo bash
```

Веб-авторизация, управление VPN-пользователями и выдача подключений ещё не реализованы.
Полная установка на чистом VPS и выпуск/продление публичного сертификата не проверены.
Текущая версия публикуется как предварительная (`prerelease`).
