# ProxyK Admin 0.1.0

Первый технический релиз: установка инфраструктуры панели на Ubuntu/Debian,
Go-приложение, SQLite, Xray-core и HTTPS.

- Docker Engine и Compose Plugin устанавливаются автоматически из официального
  репозитория; `INSTALL_DOCKER=1` и подтверждение больше не нужны.
- Конфликтующие пакеты, включая `docker.io`, заменяются без очистки данных Docker.
  Замена может временно остановить существующие контейнеры.
- Остановленная служба Docker запускается автоматически.
- В релиз включены установщик, архив исходников и файл контрольных сумм SHA-256.

Установка:

```bash
curl -fsSL https://github.com/kkirill412/proxyk-admin-linux/releases/download/v0.1.0/install.sh | sudo bash
```

Веб-авторизация, управление VPN-пользователями и выдача подключений ещё не реализованы.
Полная установка на чистом VPS и выпуск/продление публичного сертификата не проверены.
Текущая версия публикуется как предварительная (`prerelease`).
