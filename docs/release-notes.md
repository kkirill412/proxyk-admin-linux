# ProxyK Admin 0.3.0

Веб-панель поддерживает вход администратора и управление VPN-пользователями.
В браузере можно создавать подключения, копировать VLESS-ссылки, открывать QR-коды,
менять лимиты, блокировать и удалять пользователей. Статистика трафика хранится
в SQLite и сохраняется после перезапуска. При исчерпании лимита Xray отклоняет новые
подключения. Уже открытые туннели продолжают работать.

Установка на новый сервер

```bash
curl -fsSL https://github.com/kkirill412/proxyk-admin-linux/releases/download/v0.3.0/install.sh | sudo bash
```

Для стандартной установки v0.2.0 выполните обновление по SSH.

```bash
curl -fsSL https://github.com/kkirill412/proxyk-admin-linux/releases/download/v0.3.0/install.sh | sudo bash -s -- --upgrade
```

Сохраняются администратор, пользователи, ключи REALITY и выданные ссылки.
Панель проверена в Chromium и с реальной передачей трафика через Xray.
Релиз помечен `prerelease`. Проверки чистого VPS и автоматического продления
публичного сертификата ещё предстоят.
